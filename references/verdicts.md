# Verdicts

Three options per surface. KEEP, FIX, BURY. No fourth, and specifically no "monitor," which is how a surface stays broken for another two years while appearing on a list.

A surface with no verdict was not audited. If it cannot be given one, it goes in the unverified section with the reason.

## KEEP

It is current, it says the right thing, and it is doing work. Leave it alone.

KEEP is not the default and it is not a shrug. It is a finding, and the output needs them, because a list of only problems misrepresents the situation and nobody runs the audit twice.

Say what the surface is doing well, in a clause. "Ranks first for the brand name and the description is current." That tells the user what to protect.

A surface can be old and still KEEP. Age is not decay.

## FIX

It earns its place and says something wrong, stale, or nothing at all.

Every FIX needs the specific change written out. Not "update the bio." The replacement text, or the exact field and what goes in it. A FIX without the change attached is a task the user now has to do the thinking for, which means it will not happen.

Rough order of what to fix first, when there are many:

1. **Anything factually wrong** that a stranger would act on. Prices, availability, contact routes, current role
2. **Whatever ranks first.** Fixing the fourth result while the first one is wrong is backwards
3. **The hand.** Contradictory self-descriptions, fixed in one pass across every surface at once
4. **Invisible pages.** Anything returning nothing to a crawler or a link preview
5. **Everything else**

## BURY

Take it down, redirect it, or deindex it.

This is the verdict people resist and it is the one that does the most work. The instinct is always to rewrite rather than remove, so a dead page gets a fresh coat every eighteen months and continues to help nobody.

Bury when **all** of these are true:

- It has no meaningful traffic and no inbound links worth keeping
- Its claim is no longer one they want to make
- Something else already covers the same ground better
- It is owned or claimed, so removal is actually possible

If it has links or traffic but the content is wrong, that is a redirect rather than a deletion. Point it at the page that replaced it and keep the value.

If it is thin and unlinked and nobody arrives, delete it.

Never bury on a hunch about traffic. If there is no data, say the verdict depends on checking it and name where to look.

## Third-party surfaces

They cannot be fixed or buried, so they get a different set.

- **Outrank.** Publish something stronger on an owned surface and let it rise. Slow, uncertain, and the only honest answer most of the time
- **Correct through the platform.** Directories, data brokers and some publications have a real correction or removal process. Use theirs
- **Accept.** It is true, it is fine, it is not going anywhere. Say so and stop spending attention on it

**Never recommend pressuring a publisher to remove accurate coverage**, however unflattering. Not a takedown, not a complaint framed as a correction, not a legal threat. The only acceptable moves against a true article are better work and time.

A factual error in a published piece is different. Correcting that through the outlet's own process is legitimate, and the request should be specific about what is wrong.

## The blocking rule

**Nothing new gets made until the contradictions are resolved.**

This belongs in the output, stated plainly, and it will be unpopular. The hand fix is boring and the new thing is fun.

It holds because a new surface built on top of an unresolved contradiction inherits it, and now there are twelve descriptions instead of eleven. The new piece also tends to be the one that gets the attention, which means the contradiction gets louder rather than quieter.

The fix is usually under an hour of unglamorous editing across a handful of profiles. Say that, because people assume it is bigger than it is and defer it for that reason.

## Writing the verdicts up

One line per surface. Verdict, then the action, then nothing else.

```
KEEP   GitHub profile README     Current, ranks second on the name, claim matches
FIX    Site About page           Replace the headline with the one claim; it still
                                 says "agency" and nothing else does
FIX    Conference speaker page   Bio is two roles old. Send them the current one
BURY   Old campaign landing page No traffic, no links, offer expired in 2024
OUT    Data-broker listing       Third-party, asserts a former employer. Correction
                                 form exists. Low priority, not worth a fight
```

Resist grouping them into themes. The list is more useful flat, because the user works through it in order and ticks things off.
